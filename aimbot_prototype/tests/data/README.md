Test fixtures.

`IR_DRONE_104_LABELS.mat` and `IR_BIRD_015_LABELS.mat` are two label files of the Halmstad
drone detection dataset (Svanström, Alonso-Fernandez, Englund, "A dataset for multi-sensor drone
detection", Data in Brief 2021; https://github.com/DroneDetectionThesis/Drone-detection-dataset),
released under CC0 1.0. They exercise frames with a drone and a bird at the same time and frames
with several birds.
